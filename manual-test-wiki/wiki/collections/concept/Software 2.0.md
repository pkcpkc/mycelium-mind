## Definition
Software 2.0 refers to a paradigm shift in programming where software is defined by optimization (training neural networks) rather than explicit human-written instructions (Software 1.0). In this model, the "code" is represented by the weights of a neural network, and the "programming" happens through data and loss functions.

## Key Characteristics
- **Optimization-based Programming**: Instead of writing `if-then` statements, developers provide a set of data and an objective function; the system learns the optimal weights to satisfy that objective.
- **Data as Code**: Data becomes the primary driver of software behavior, where high-quality datasets act as the specification for the desired output.
- **Neural Network Weights**: The weights of a [[Deep Neural Networks]] model serve as the executable program.

## Context & Influence
- **Key Proponent**: Prominently advocated by [[Andrej Karpathy]], particularly regarding the evolution of computer vision and autonomous systems.
- **Industrial Application**: Heavily utilized in Tesla's Autopilot systems to move away from hand-coded heuristics toward end-to-end neural network models.
