# PyTorch

[[PyTorch]] is an open-source machine learning framework developed by [[Facebook]]'s AI Research lab. [[Andrej Karpathy]] has been a prominent advocate and user of PyTorch throughout his career.

## Karpathy's PyTorch Work

- **PyTorch at Tesla** (PyTorch DevCon 2019) — Presented on PyTorch usage at Tesla for Autopilot
- **Micrograd** — His autograd engine was designed with a PyTorch-like API
- Built the Software 2.0 stack at Tesla using PyTorch

## Related Talks

- **PyTorch at Tesla** @ PyTorch DevCon 2019
- **Building the Software 2.0 stack** @ Spark-AI 2018

## In Educational Content

- Karpathy's educational series [[Zero to Hero]] teaches neural networks with concepts directly transferable to PyTorch
- **Micrograd** provides a from-scratch implementation of autograd with a PyTorch-like interface
