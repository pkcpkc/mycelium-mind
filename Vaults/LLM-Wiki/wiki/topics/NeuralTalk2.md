# NeuralTalk2

[[NeuralTalk2]] is an early image captioning project created by [[Andrej Karpathy]] using the [[Torch]] deep learning framework. It generates natural language descriptions of images.

## Technical Details

- Built in [[Torch]] (Lua-based deep learning framework)
- Image captioning: generates text descriptions from images
- Part of Karpathy's early work bridging computer vision and natural language

## Later Extensions

Karpathy extended NeuralTalk2 with [[Justin Johnson]] to include **dense captioning**, which provides localized descriptions for different regions of an image rather than a single caption for the entire image. This work evolved into the **DenseCap** paper (CVPR 2016, Oral).

## Related Work

- **DenseCap** (CVPR 2016, Oral) — Fully convolutional localization networks for dense captioning
- **Deep Visual-Semantic Alignments** (CVPR 2015, Oral) — Earlier image description work

## Significance

NeuralTalk2 was one of the early demonstrations of neural image captioning and helped establish the field of vision-language understanding.
