# Char-RNN

[[Char-RNN]] is a character-level language model built using [[Torch]], implementing LSTMs, GRUs, and RNNs. It was created by [[Andrej Karpathy]] and is closely related to his influential blog post *The Unreasonable Effectiveness of Recurrent Neural Networks*.

## Technical Details

- Built in [[Torch]] (Lua-based deep learning framework)
- Character-level generative model
- Uses LSTMs, GRUs, or RNNs as the core architecture
- Generates text one character at a time

## Related Work

- **The Unreasonable Effectiveness of Recurrent Neural Networks** (2015) — Blog post exploring the surprising effectiveness of RNNs, featuring Char-RNN examples
- **Minimal RNN gist** — A minimal implementation reference

## Evolution

Char-RNN was an early demonstration of neural text generation and helped popularize the use of RNNs and LSTMs for natural language tasks. It preceded Karpathy's later work on building large language models from scratch in his [[Zero to Hero]] series.
