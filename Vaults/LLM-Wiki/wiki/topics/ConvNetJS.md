# ConvNetJS

[[ConvNetJS]] is a deep learning library written entirely in JavaScript, created by [[Andrej Karpathy]]. It enables browser-based training and inference of neural networks, allowing users to run deep learning experiments directly in web browsers.

## Key Features

- Written entirely in JavaScript — no server required
- Supports convolutional neural networks (CNNs) and feedforward networks
- Web-based demos for various neural network experiments
- Interactive visualizations of training

## Related Projects

Karpathy created several follow-up JavaScript-based ML projects:

- **[[t-SNEJS]]** — t-SNE visualization in JavaScript
- **REINFORCEjs** — Reinforcement learning in JavaScript
- **recurrentjs** — Recurrent neural networks in JavaScript
- **GANs in JS** — Generative adversarial networks in JavaScript

## Impact

ConvNetJS made deep learning accessible to web developers and students by allowing them to train and visualize neural networks without any setup or backend infrastructure. Karpathy discussed the library and its backstory in an interview with Data Science Weekly.

## Connection to ImageNet

The browser-based nature of ConvNetJS demos allowed people to interact with CNN concepts that were typically reserved for large-scale ImageNet-scale research.
