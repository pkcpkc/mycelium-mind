# Deep Learning

[[Deep Learning]] is a subfield of machine learning focused on neural networks with multiple layers. [[Andrej Karpathy]] has been a prominent figure in deep learning research, education, and application since attending [[Geoff Hinton]]'s classes at the [[University of Toronto]] in 2005.

## Karpathy's Contributions

- **CS231n** — Designed and taught the first deep learning class at [[Stanford University]], covering Convolutional Neural Networks for Visual Recognition
- **Zero to Hero** — Educational lecture series teaching neural networks and LLMs from scratch, covering backpropagation, batch normalization, and building GPT
- **Software 2.0** — Blog post (2017) articulating the paradigm of deep learning-driven software
- **The Unreasonable Effectiveness of Recurrent Neural Networks** (2015) — Influential blog post on RNNs

## Key Concepts

- **Convolutional Neural Networks (CNNs)** — Used extensively in Karpathy's computer vision work, including ImageNet classification and image captioning
- **Recurrent Neural Networks (RNNs)** — Used in Karpathy's Char-RNN project and blog post
- **Backpropagation** — Covered in detail in Karpathy's spelled-out intro lectures
- **Batch Normalization** — Covered in Karpathy's makemore series

## Educational Resources

- **[[Zero to Hero]]** — Lecture series on neural networks from scratch
- **Micrograd** — Tiny scalar-valued autograd engine for learning backpropagation
- **[[ConvNetJS]]** — Deep learning library written in JavaScript for browser-based demos
