# arxiv-sanity

[[arxiv-sanity]] is a tool created by [[Andrej Karpathy]] to help researchers navigate the overwhelming volume of papers published on Arxiv. It allows researchers to discover relevant papers, search and sort by similarity, view recent and popular papers, and receive recommendations.

## Features

- Discover relevant research papers
- Search and sort by similarity
- View recent and popular papers
- Paper recommendations

## Live Site

Deployed at arxiv-sanity.com

## Evolution

Karpathy's most recent from-scratch rewrite of the tool is called **arxiv-sanity-lite**, which he describes as much better than the original.

## Significance

arxiv-sanity addresses a real problem faced by researchers in the era of exponential paper growth, using machine learning to make academic literature more navigable.
