# Torch

[[Torch]] is an open-source machine learning framework and scientific computing library, originally written in the Lua programming language. [[Andrej Karpathy]] used Torch extensively early in his career for several research projects.

## Karpathy's Torch Projects

- **[[Char-RNN]]** — Character-level language model using LSTMs/GRUs/RNNs
- **[[NeuralTalk2]]** — Early image captioning project

## Transition to PyTorch

Karpathy later transitioned from Torch to [[PyTorch]], which is the Python-based successor to Torch. At [[Tesla]], he used PyTorch to build the Software 2.0 stack for Autopilot.

## Related Publications

- *The Unreasonable Effectiveness of Recurrent Neural Networks* (2015) — Featured Char-RNN examples built in Torch
- *NeuralTalk2* — Image captioning in Torch

## Legacy

Torch was influential in the early deep learning ecosystem, and many of its concepts and APIs were carried forward into PyTorch. Karpathy's work on Torch helped establish it as a major deep learning framework before the PyTorch transition.
