# ConvNetJS

## Summary

ConvNetJS is a deep learning library written entirely in JavaScript that enables browser-based demos for training convolutional neural networks and other neural network architectures.

## Key Details

- Created by **Andrej Karpathy** as part of his open-source project portfolio.
- The library allows users to build and train neural networks directly in the browser without requiring a backend server.
- It supports training convolutional neural networks, making it useful for educational demos and prototyping computer vision models.
- ConvNetJS is listed among Karpathy's notable open-source projects alongside **micrograd**, **char-rnn**, **arxiv-sanity**, and **neuraltalk2**.
- The library demonstrates the accessibility of deep learning by running entirely client-side in JavaScript.
