# NeuralTalk2

## Summary

NeuralTalk2 is an early image captioning project built by Andrej Karpathy using Lua Torch that combines convolutional and recurrent neural networks to generate natural language descriptions of images.

## Key Details

- **Framework**: Lua Torch
- **Author**: Andrej Karpathy
- **Approach**: Combines CNNs for visual feature extraction with RNNs/LSTMs for language generation
- **Purpose**: Generates natural language descriptions (captions) from input images
- **Relation to Torch**: One of the notable projects built on the Lua Torch ecosystem alongside `char-rnn`
