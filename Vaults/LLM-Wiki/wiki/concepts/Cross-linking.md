# Cross-linking

## Summary

Cross-linking refers to the practice of connecting individual concepts within a knowledge system using standard markdown links. This approach forms a directed graph structure that allows semantic relationships between nodes to be conveyed not just through the links themselves, but also through the surrounding prose. It serves as a foundational mechanism for navigating and understanding complex knowledge bundles without requiring centralized registries or proprietary tooling.

## Key Details

- Utilizes standard markdown link syntax (`[[Target]]`) to establish connections between concept pages.
- Forms a directed graph topology across the knowledge bundle, enabling non-linear navigation and conceptual mapping.
- Semantic context is reinforced by surrounding text, allowing meaning to be derived from both the link and its narrative environment.
- Designed for resilience and scalability, supporting graceful handling of broken links or missing targets in permissive consumption models.
- Eliminates the need for fixed taxonomies or centralized registries, relying instead on emergent network structures to organize information.
