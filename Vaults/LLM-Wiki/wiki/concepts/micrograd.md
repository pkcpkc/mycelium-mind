# micrograd

micrograd is a tiny scalar-valued autograd engine created by Andrej Karpathy. It implements backpropagation (reverse-mode automatic differentiation) over a dynamically built directed acyclic graph (DAG) and provides a small neural networks library on top of it with a PyTorch-like API. [Source: Andrej_Karpathy.md]

**Purpose:** micrograd is designed as an educational tool to help students understand the internals of neural network training and automatic differentiation. [Source: Andrej_Karpathy.md]

**Key Features:**
- Scalar-valued automatic differentiation
- Reverse-mode autodiff (backpropagation)
- Dynamic DAG construction
- PyTorch-like API for neural network layers [Source: Andrej_Karpathy.md]
