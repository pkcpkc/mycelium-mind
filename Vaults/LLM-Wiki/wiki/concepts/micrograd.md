# micrograd

## Summary

micrograd is a tiny scalar-valued autograd engine built by **Andrej Karpathy** that implements backpropagation (reverse-mode autodiff) over a dynamically built DAG, with a **PyTorch**-like API.

## Key Details

- Implements reverse-mode automatic differentiation over a dynamically constructed computation graph (DAG).
- Provides a minimal but complete implementation of backpropagation.
- Designed with a **PyTorch**-like API for educational clarity.
- Featured in **Andrej Karpathy**'s **Zero to Hero** YouTube playlist as a foundational building block for understanding neural network training.
