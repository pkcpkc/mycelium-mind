# micrograd

## Summary

micrograd is a lightweight, educational Python library that implements automatic differentiation (autograd) and basic neural network components from scratch. Created by AI researcher Andrej Karpathy, it serves as a pedagogical tool to demystify the mathematical and computational foundations of deep learning, particularly backpropagation and tensor operations, without relying on large production frameworks.

## Key Details

- Single-file Python implementation (~100 lines of code) that is highly readable and easily modifiable.
- Implements reverse-mode automatic differentiation to efficiently compute gradients through computation graphs.
- Includes fundamental neural network building blocks such as linear layers, ReLU activations, and standard loss functions.
- Designed explicitly for teaching purposes, closely aligning with Karpathy's "Neural Networks: Zero to Hero" educational series.
- Demonstrates core concepts of how modern deep learning frameworks like PyTorch handle forward passes, backward passes, and gradient tracking under the hood.
