# Torch

## Summary

Torch is an open-source machine learning library and ecosystem originally developed by Facebook AI Research (FAIR), written primarily in the Lua programming language. It provided a wide range of algorithms for optimization and machine learning, and became one of the most influential frameworks in early deep learning research.

## Key Details

- **Language**: Primarily Lua, with CUDA support for GPU acceleration
- **Creator**: Facebook AI Research (FAIR)
- **Key Components**: Torch7 (core library), nn (neural network library), torch-torch (tensor operations), dp (distributed parallel computing), trepl (LuaJIT-based REPL)
- **Ecosystem**: Inspired the creation of PyTorch, a Python port that became widely adopted in both academia and industry
- **Notable Projects**: Andrej Karpathy's `char-rnn` (character-level language models using LSTMs, GRUs, and RNNs) and `neuraltalk2` (image captioning) were built using Lua Torch
- **Legacy**: The success of PyTorch led to Torch's gradual deprecation, with the official Torch repository archived in 2020
