# char-rnn

## Summary

char-rnn is an open-source character-level language model built by **Andrej Karpathy** using **Torch**, implementing RNNs, LSTMs, and GRUs for text generation.

## Key Details

- Built using the **Torch** deep learning framework.
- Implements character-level language modeling with **LSTMs**, **GRUs**, and vanilla **RNNs**.
- One of **Andrej Karpathy**'s influential early open-source projects.
- Demonstrates the power of recurrent neural networks for sequence modeling and text generation.
