# GitHub

## Summary

**GitHub** is a web-based platform for version control and collaboration using Git, serving as the primary hosting platform for open-source projects and developer portfolios in the AI and software engineering communities.

## Key Details

- **Andrej Karpathy** maintains a blog on GitHub, with notable posts including "A Recipe for Training Neural Networks", "The Unreasonable Effectiveness of Recurrent Neural Networks", and "Software 2.0".
- Karpathy hosts numerous open-source projects on GitHub, including **micrograd**, **char-rnn**, **arxiv-sanity**, **neuraltalk2**, and **ConvNetJS**.
- GitHub is a key platform for the AI community to share code, research implementations, and engage with other developers.
- Karpathy actively engages on GitHub for sharing updates on his work alongside **X** (formerly Twitter).
