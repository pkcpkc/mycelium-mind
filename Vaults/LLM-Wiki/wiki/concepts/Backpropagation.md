# Backpropagation

Backpropagation (reverse-mode autodiff) is the fundamental algorithm for training neural networks. It computes gradients of the loss function with respect to each weight by applying the chain rule backward through the network.

## Key Facts

- [[Andrej Karpathy]] created extensive educational resources on backpropagation, including "The spelled-out intro to neural networks and backpropagation" (1.2M views).
- [[micrograd]] is a tiny scalar-valued autograd engine implementing backpropagation over a dynamically built DAG.
